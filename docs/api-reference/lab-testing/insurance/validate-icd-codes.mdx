---
title: "Validate ICD Codes"
description: "Check ICD-10-CM codes for unknown or inactive codes, missing primary diagnoses, and conflicting code combinations before ordering."
openapi: "POST /v3/insurance/validate_icd_codes"
---

<RequestExample>

```bash cURL
curl --request POST \
     --url 'https://api.us.junction.com/v3/insurance/validate_icd_codes' \
     --header 'Content-Type: application/json' \
     --header 'x-vital-api-key: YOUR_API_KEY' \
     --data '{"codes": ["G93.3"]}'
```

</RequestExample>

<ResponseExample>

```json "Unknown or inactive code"
{
  "valid": false,
  "errors": ["Unknown or inactive codes: G93.3"],
  "violations": [],
  "warnings": []
}
```

</ResponseExample>
