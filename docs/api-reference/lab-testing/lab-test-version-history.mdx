---
title: "Get Lab Test Version History"
description: "List the immutable marker-set versions for a lab test via the Junction API. Requires authentication with your team API key."
openapi: "GET /v3/lab_tests/{lab_test_id}/version"
---

Returns the marker set recorded for each version of a lab test, ordered as a paginated history.

<RequestExample>

```bash cURL
curl --request GET \
     --url '{{BASE_URL}}/v3/lab_tests/<lab_test_id>/version?size=50' \
     --header 'accept: application/json' \
     --header 'x-vital-api-key: YOUR_API_KEY'
```

</RequestExample>
