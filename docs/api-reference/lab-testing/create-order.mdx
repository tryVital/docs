## Fasting requirement

Set `order_set.parameters.fasting` to override the fasting requirement for the order. This parameter specifies whether fasting is required before sample collection. It does not record whether the patient has actually fasted.

| Value | Behavior |
| --- | --- |
| `"fasting_required"` | Require fasting for this order, regardless of the selected lab tests' fasting settings. |
| `"fasting_not_required"` | Do not require fasting for this order, regardless of the selected lab tests' fasting settings. |
| Omitted or `null` | Use the default behavior described below. |

When you omit the parameter or set it to `null`:

- With `lab_test_ids` only, fasting is required if any selected lab test requires it. For a single lab test, its fasting setting is preserved.
- With `add_on`, fasting is required by default, including when you also provide `lab_test_ids`.

Use `order_set.lab_test_ids` instead of the top-level `lab_test_id` when supplying this parameter. For example, include the following `order_set` in your create-order request to order a saved lab test without requiring fasting:

```json
{
  "order_set": {
    "lab_test_ids": ["5b41f610-ebc5-4803-8f0c-a61c3bdc7faf"],
    "parameters": {
      "fasting": "fasting_not_required"
    }
  }
}
```

The override applies to the lab test used for this order. It does not change your saved lab tests, and normal test approval and ordering requirements still apply.

<Note>
Explicit fasting answers supplied in `aoe_answers` take precedence over the lab test's effective fasting setting for the corresponding [Ask on Order Entry (AOE) question](/lab/workflow/aoe). If you do not supply a fasting answer, Junction uses the effective fasting setting, including any override from `order_set.parameters.fasting`.
</Note>


## Collection Instructions

### LabCorp

When enabled for your team, Junction uses Labcorp AccuDraw to generate a specimen collection guide PDF for Labcorp orders using `at_home_phlebotomy`, `walk_in_test`, or `on_site_collection` modalities. This guide is separate from the requisition and is intended for phlebotomists or clinical staff collecting and preparing the specimens. [Contact Junction support](/home/getting-support) to enable collection instructions and PDF access.

#### What the guide contains

Junction generates the guide from the order's Labcorp test codes and selected lab account (see [Lab Accounts](/lab/overview/lab-accounts)), so the handling and shipping instructions reflect the account used for that order. Based on the instructions returned by AccuDraw, the PDF includes:

- Required collection containers and quantities, with tube images when available.
- The collection sequence, container sizes, expected sample yields, and special draw instructions.
- Transport containers, storage temperatures, processing volumes, and shipping details, including destination labs when supplied.
- The Labcorp account and test codes and names covered by the guide.

If AccuDraw returns instructions for only some tests, the PDF is labeled as a partial guide and lists the uncovered tests with guidance from Labcorp.

#### When instructions are generated

After the order is created, Junction attempts to generate and save the guide before submitting the requisition to Labcorp. For orders with a future `activate_by` date, generation is deferred until the order is due for submission. These guides are not automatically generated for sandbox orders or testkit orders.

A failure to generate the guide does not prevent requisition submission. A successfully created order or requisition therefore does not guarantee that collection instructions are available.

#### Downloading and using the guide

Retrieve the saved PDF with [Get Collection Instructions PDF for Order](/api-reference/lab-testing/order-collection-instructions-pdf): `GET /v3/order/{order_id}/collection_instruction_pdf`. The endpoint returns `application/pdf` when the guide is available and `404` when the order has no saved guide. Downloading does not generate or regenerate instructions.

For at-home phlebotomy appointments, Junction attaches the saved guide to the provider's appointment when available. Booking does not call AccuDraw again and can continue if the guide is unavailable.

```java Java
import com.junction.api.Junction;
import com.junction.api.core.Environment;
import com.junction.api.resources.labtests.requests.CreateOrderRequestCompatible;
import com.junction.api.types.Gender;
import com.junction.api.types.PatientAddressWithValidation;
import com.junction.api.types.PatientDetailsWithValidation;

Junction client = Junction.builder()
    .apiKey("YOUR_API_KEY")
    .environment(Environment.SANDBOX)
    .build();

var data = client.labTests().createOrder(
    CreateOrderRequestCompatible.builder()
        .userId("63661a2b-2bb3-4125-bb1a-b590f64f057f")
        .patientDetails(
            PatientDetailsWithValidation.builder()
                .firstName("John")
                .lastName("Doe")
                .dob("2020-01-01")
                .gender(Gender.MALE)
                .phoneNumber("+1123456789")
                .email("email@email.com")
                .build()
        )
        .patientAddress(
            PatientAddressWithValidation.builder()
                .firstLine("123 Main St.")
                .city("San Francisco")
                .state("CA")
                .zip("91189")
                .country("US")
                .build()
        )
        .labTestId("5b41f610-ebc5-4803-8f0c-a61c3bdc7faf")
        .build()
);
```
