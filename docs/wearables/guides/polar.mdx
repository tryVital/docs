## Historical backfill with Polar

Junction backfills these Polar resources:

- Activity and Steps
- Body, Weight and Profile
- Sleep, including Sleep Cycle, Heart Rate, HRV and Respiratory Rate

The default backfill window is 28 days. You can change it through [Team Data Pull Preferences](/wearables/providers/historical-data-pull-range): Activity can be configured up to 365 days, and the other resources up to 28 days.
