---
title: "Find Patient Service Centers"
description: "Find supported Patient Service Centers for walk-in collection using the Area Info and PSC Info endpoints."
---

A Patient Service Center (PSC) is a partner laboratory location where staff can collect a sample for a walk-in order. Find a PSC belonging to the same laboratory as the test being ordered.

## 1. Check coverage

Call the [Area Info endpoint](/api-reference/lab-testing/area-info) with the patient's ZIP code. The `central_labs` response identifies laboratories with nearby PSCs, the search radius, and the capabilities available within that radius.

```json
{
  "zip_code": "85004",
  "central_labs": {
    "labcorp": {
      "within_radius": 5,
      "radius": "25",
      "capabilities": ["stat", "appointment_scheduling_with_lab"]
    }
  }
}
```

## 2. Retrieve locations

Call the [PSC Info endpoint](/api-reference/lab-testing/psc-info) to retrieve addresses, operating hours, distance, site codes, and capabilities for individual locations.

```json
{
  "lab_id": 27,
  "slug": "labcorp",
  "patient_service_centers": [
    {
      "metadata": {
        "name": "LABCORP",
        "state": "AZ",
        "city": "Phoenix",
        "zip_code": "85006",
        "first_line": "1300 N 12th St",
        "second_line": "Ste 300",
        "phone_number": "480-878-3988",
        "hours": null
      },
      "distance": "25",
      "site_code": "ABC",
      "capabilities": ["appointment_scheduling_with_lab"]
    }
  ]
}
```

If `hours` is `null`, direct the patient to confirm operating hours with the laboratory before visiting.

## Scheduling capabilities

| Capability | Meaning |
| --- | --- |
| `appointment_scheduling_via_junction` | The location supports appointment scheduling through Junction's API. |
| `appointment_scheduling_with_lab` | The patient can schedule directly with the laboratory, but not through Junction's API. |

If neither capability is present, the location either does not offer appointments or its scheduling availability is unknown. Appointments are not required for most walk-in collections.

To book a supported Quest location through Junction, continue to [Schedule PSC Appointments](/lab/walk-in/psc-appointment-scheduling).
