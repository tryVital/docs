---
title: "Lab Accounts"
description: "Manage lab accounts that link your team to partner laboratories for order routing and result delivery configuration."
---
Lab accounts contain the configuration Junction needs to place orders and receive results from a specific lab. Each customer-owned lab account belongs to an Org and can be linked to one or more Teams. Junction platform accounts are managed by Junction and are not owned by a customer Org.

A Team can have multiple lab accounts linked, including multiple accounts for the same lab, but each order uses only one lab account.

## Ordering with a lab account ID

<Note>
  You only need to provide `lab_account_id` if you have your own account with a core lab. If your Team uses Junction's platform accounts, you do not need to provide it when placing an order.
</Note>

If you have your own core lab account, provide [`lab_account_id`](/api-reference/lab-testing/create-order#body-lab-account-id-one-of-0) when you want an order to be placed with that account rather than Junction's platform account. This makes your intended account explicit and ensures that Junction uses that lab account's configuration when routing the order. Your lab account must be active, linked to your Team, and associated with the lab selected for the order.

The relevant fields in the [Create Order](/api-reference/lab-testing/create-order) request are:

```json
{
  "lab_account_id": "<lab_account_id>",
  "order_set": {
    "lab_test_ids": ["<lab_test_id>"]
  }
}
```

Before placing an order, use the [Get Lab Accounts (Team-level)](/api-reference/lab-testing/lab_accounts) endpoint to retrieve the lab accounts available to your Team and select the appropriate `id`.

### How Junction selects a lab account when `lab_account_id` is omitted

When `lab_account_id` is omitted from a [Create Order](/api-reference/lab-testing/create-order) request, Junction evaluates the lab accounts linked to your Team for the lab selected by the order:

| Lab accounts linked to your Team for the selected lab | Account selection |
| --- | --- |
| No lab accounts are linked | Junction uses its platform account when one is available to your Team for that lab. |
| Exactly one active lab account is linked | Junction uses your active linked account. |
| More than one active lab account is linked | Junction does not select an account because it cannot determine which of your accounts you intended to use. |
| Lab accounts are linked, but none is active | Junction does not fall back to its platform account. |

<Warning>
  If more than one active lab account is linked to your Team for the selected lab, the order may be rejected unless you provide `lab_account_id`. Junction cannot place the order if no active account is available.
</Warning>

## Billing types

Each lab account defines the billing types it supports and the states where each type is available. Each lab account object returned by [Get Lab Accounts (Team-level)](/api-reference/lab-testing/lab_accounts) includes an `allowed_billing` field such as:

```json
{
  "allowed_billing": {
    "client_bill": ["AZ", "CA", "NY"],
    "commercial_insurance": ["AZ", "CA"]
  }
}
```

Each key is a supported `billing_type`, and its value lists the patient states where that billing type is available for the account. If a billing type is absent, the lab account does not support it. If the patient's state is absent from its list, that billing type is not available for the account in that state.

The `billing_type` in a [Create Order](/api-reference/lab-testing/create-order) request must be supported by the lab account used for the order. For the additional requirements associated with `commercial_insurance`, see [Insurance Ordering](/lab/overview/insurance).

## Retrieving and managing lab accounts

Use the Team-level endpoint to retrieve the accounts available to your Team for ordering. Use the Org-level endpoint to retrieve accounts across your Org and review which Teams are linked to each account.

| Topic | [Org-level Get Lab Accounts](/api-reference/org-management/lab-accounts/get-lab-accounts) | [Team-level Get Lab Accounts](/api-reference/lab-testing/lab_accounts) |
| ----- | ----- | ----- |
| Scope | Returns lab accounts for the Org, across Teams | Returns lab accounts available to the current Team |
| Typical user | Org admin or platform integrator | Team-scoped integration |
| Best use case | Org-wide visibility and management | Team-specific runtime operations |
| Team linkage | Shows which Teams are linked to each account | Returns only accounts linked to the current Team |

Manage Team linkage through the [Update Lab Account Teams (Org-level)](/api-reference/org-management/lab-accounts/update-lab-account-teams) endpoint. There is no Team-level endpoint for updating lab account linkage.

You can also view lab accounts tied to your Org on the [Lab Interface Requests page of your Org Config](https://app.junction.com/org/lab-interface-requests) in the Junction dashboard.
