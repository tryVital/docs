---
title: "Creating a Lab Test"
description: "Create a reusable lab test from orderable markers and understand when it is ready to use."
---

A lab test is a reusable set of markers for a specific partner laboratory and collection method. Create a lab test when you expect to order the same group of markers more than once. For one-off selections, you can instead [choose markers à la carte](/lab/workflow/ordering#choose-markers-à-la-carte) when creating an order.

## Before you create a lab test

Your lab test must include:

- One or more active, orderable markers from the same partner laboratory.
- One collection method supported by that laboratory: `testkit`, `walk_in_test`, `at_home_phlebotomy`, or `on_site_collection`.
- Either Junction `marker_ids` or the laboratory's `provider_ids`. Do not provide both.

We recommend using `provider_ids` when the laboratory supplies them because they are shared across environments. Otherwise, use `marker_ids`.

<Note>
  [Contact the Junction team](/home/getting-support) if you need help confirming your panel requirements.
</Note>

## Approval status

The `status` in the create response determines whether the lab test can be ordered. Only lab tests with a status of `active` can be used in an order.

In production, the initial status depends on the collection method and marker configuration:

| Collection method | Status after creation |
| --- | --- |
| `at_home_phlebotomy` | `pending_approval`. Mobile phlebotomy lab tests currently require review because of panel constraints from our phlebotomy provider, even when every marker is enabled for à-la-carte ordering. |
| `testkit` | `pending_approval`. Test kit lab tests require review. |
| `walk_in_test` | `active` when every marker is enabled for à-la-carte ordering; otherwise `pending_approval`. |
| `on_site_collection` | `active` when every marker is enabled for à-la-carte ordering; otherwise `pending_approval`. |

For teams using a delegated lab account, walk-in and on-site lab tests are created as `active` regardless of the markers' à-la-carte settings.

If a production lab test is created with `pending_approval`, Junction reviews the panel before changing its status to `active`. You can check the current status using the [List Lab Tests endpoint](/api-reference/lab-testing/tests-paginated).

<Note>
  In Sandbox, newly created lab tests are active immediately. Production approval rules are not applied in Sandbox.
</Note>

## 1. Find markers

Use [`GET /v3/lab_tests/markers`](/api-reference/lab-testing/biomarkers) to find the markers available for the partner laboratory. The response indicates whether each marker supports à-la-carte ordering.

```json Get all markers
{
  "markers": [
    {
      "id": 1,
      "name": "17-OH Progesterone LCMS",
      "slug": "17-oh-progesterone-lcms",
```

You can set the `a_la_carte_enabled` query parameter to `true` to return only markers that support à-la-carte ordering.

## 2. Create the lab test

Use [`POST /v3/lab_tests`](/api-reference/lab-testing/post-test) with the selected marker or provider IDs. The following Sandbox example creates a Labcorp walk-in test from provider IDs:

```python Create a lab test
from junction import Junction, LabTestCollectionMethod
from junction.environment import JunctionEnvironment

client = Junction(
    api_key="YOUR_API_KEY",
    environment=JunctionEnvironment.SANDBOX,
)

lab_test = client.lab_tests.create(
    name="Example test",
    description="Example test",
    method=LabTestCollectionMethod.WALK_IN_TEST,
    provider_ids=["006056", "070085"],
)
```

The response contains the new lab test and its current status:
